⚙️ Konfigurasi Google Sheets
Hubungkan aplikasi ke Google Sheets sebagai database
Salin dari URL Google Sheets Anda: docs.google.com/spreadsheets/d/[ID]/edit
Buat di console.cloud.google.com → APIs & Services → Credentials
💡 Panduan Setup:
1. Buat Google Sheet baru → tambahkan kolom: Tanggal, Jenis, Kategori, Deskripsi, Nominal, ID
2. Aktifkan Google Sheets API di Google Cloud Console
3. Buat API Key dan masukkan di atas
4. Bagikan Sheet dengan "Anyone with link can view"
5. Untuk menulis data, gunakan Google Apps Script Web App sebagai proxy
Deploy Apps Script sebagai Web App untuk menulis data ke Sheet
